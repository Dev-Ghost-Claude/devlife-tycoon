What it is

  • The Me sheet and the Journal in one object: a school ring binder with colour tabs. ME, SKILLS, KNOWLEDGE, PEOPLE, JOURNAL. J opens it, Tab pins or hides it, and Left and Right change tab.
  • It is read-only, so it has no primary button. The one button is a secondary: Mark on my map. Esc closes it.
  • The binder replaces the Me peek from section 4. The HUD chips stay on top, so time and stamina are never hidden.

The craft, in an era's voice

  • Each tab has its own muted colour and a matching divider strip. The open tab stands taller.
  • Section headers wear a marker squiggle and a star doodle. A rust pen loop marks the picked skill. Status marks use shapes: clock, gem, arrow.
  • The left page lists what you are learning, with a tile, a title, one line and a status. The right page holds a tile grid and a detail card. A taped map shows where to use the skill. A pencil doodle of the crow in the corner is not yours.
  • Later eras swap the object: ring binder, then terminal pages, then glossy tabs, then a flat app. The slots stay.

Rules used

  • 6 Hierarchy: header, tiles, the one selected tile, the detail card.
  • 35 Not colour alone: tab colour plus label plus icon; status icon plus word.
  • 34 Contrast: ink on every tab colour is above 6:1, and cream on denim is 5.8:1. The selected row text is ink on mustard.
  • 49 Fewer borders: list rows sit on the ruled paper. Only the selected row gets a frame.
