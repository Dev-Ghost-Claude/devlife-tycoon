What it does

  • The Game Master takes the screen. Bars close in. The HUD goes away. Time stops.
  • One click or Space moves on. Esc opens the pause menu, not skip.
  • Every box is copied to the Journal, tab Notes from the Game Master, with the same glitches.

How the garble works

  • Dither blocks hide words. Raised or dropped letters are noise.
  • Some hidden words can be solved with knowledge. Some are only mood.
  • The glitch pattern is fixed per message, so a replay shows the same riddle.

Rules used

  • 22 Line length: about 60 characters per line.
  • 8/34 No grey on colour: cream and sky on night, 12:1 and 7.7:1.
  • 35 Not colour alone: glitches also move and hide letters.
  • 9 Emphasise by quieting: the HUD leaves so the box wins.
